# Security Policy

## Supported Versions

The following versions of the Artificial Life & Evolution Simulator are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security and memory safety seriously. If you discover a vulnerability or security issue:

1. **Do not create a public GitHub issue.**
2. Please privately disclose the issue by opening a private security advisory on GitHub or contacting the repository maintainers.
3. Include detailed steps to reproduce the issue, sample code or experiment snapshots, and platform details.
4. Maintainers will respond promptly to acknowledge the report and work on a fix.
